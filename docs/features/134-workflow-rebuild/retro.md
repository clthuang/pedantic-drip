## Act — patterns, anti-patterns, heuristics (with provenance)

- **Already institutionalized — reference, don't re-mint:** the one-pass review gate protocol (CLAUDE.md:42-44, "Review gate protocol (feature 134)"), reviewer-notes-on-events replacing `.review-history.md` (CLAUDE.md:62), #060's DB-only backlog closure (CLAUDE.md:190). This retro adds no knowledge-bank entries for those; the 53-day-late lesson (Tune 1) is the only new candidate.
- **Pattern — renegotiate a collided pin with arithmetic, in the artifact, at the moment of collision:** the ≤5,000-word SC collided with FR-3's own 200–500-word band × 38-file inventory (floor ≈ 7,000); revised to ≤8,000 with the arithmetic shown and the #125 collision class named (prd.md:220, `bf860814`). - **Anti-pattern — replacing a workflow mid-flight without migrating in-flight bookkeeping:** the feature that deleted the old close-out machinery was the feature the old machinery was mid-way through tracking. Any future flow swap should enumerate in-flight entities and carry them across as part of the swap itself.
- **Heuristic — when a fix reactivates a dead path, QA the newly-live path end-to-end, not just the fix site:** three stacked latents on `skipped_phases` (#056 → skipped-overwrite → v2-view half-sweep), each invisible until the one above it fell.
