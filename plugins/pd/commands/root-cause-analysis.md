# /pd:root-cause-analysis

Clarify for a bug: every cause with its evidence and a verdict, in one rca item.

Invoke the `pd:root-cause-analysis` skill with `$ARGUMENTS`. An empty argument means asking the user for the failing command or the observed behaviour first.
