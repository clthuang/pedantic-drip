# Plan: worktree management in pd

<!-- from_shape is `git hash-object shape.md` when this plan was derived. Format: plugins/pd/references/doc-format.md. -->

## Plan

Shared terms for every case:
- **`pd_repo`:** the fixture in `plugins/pd/scripts/conftest.py` (shape.md `### Test strategy`): an adopted repository with work item `<id>` committed on `main` and branch `workitem/<id>`, the main checkout on `main`.
- **`task_worktree(n, state, id=<id>, path=.claude/worktrees/task-<n>)`:** `git worktree add -b pd/<id>/task-<n> <path>`, then `clean` (nothing), `dirty` (an untracked file), `locked` (`git worktree lock`) or `gone` (its directory deleted).
- **`wt(args)`:** runs `plugins/pd/scripts/pd-worktrees <args>` with the repository root as cwd (or the cwd a case names) and the `logging git` first on `PATH` unless the case puts another logging fake there; returns stdout split on `\n` only (a path may hold `\r`), stderr and the exit code; then applies the guard. "Expect `x`" means `x` is among the lines; "exactly" or "only" means no other lines; lines compare as a multiset unless a case says "in order".
- **Paths:** `<path n>` and `<repository root>` are absolute paths as `git worktree list --porcelain -z` reports them, read from it by the test (macOS's `tmp_path` resolves through `/private`), shown as `shown()` writes them.
- **Work item ids:** `A`, `B`, `C`, `D` and `ghost` (Task 2) and `<other>` (C7) are literal ids beside `pd_repo`'s `<id>`, each a directory under `docs/dev_artifacts/workitems/` with a README where the case says it has one; Task 2's file builds its own (`conftest.py` is Task 1's).
- **The guard:** after every `wt` call, reading only the calls logged during it (the log is emptied before each call), no logged call may carry, as a whole argument, `--force`, `-f`, `unlock` or `prune`, nor have `branch` then `-d` or `-D` as its first two arguments after any `-C <path>`, nor an `update-ref -d` of a `pd/*` or `workitem/*` ref, and every `update-ref` carries `--no-deref` (the must-nots on forcing, unlocking and deleting task branches).
- **"unchanged":** `git worktree list --porcelain` and `git for-each-ref refs/heads/` print the same before and after.
- **`logging git` / `moving git` / `occupying git`:** a `git` script first on `PATH` that appends its argument list to a log as one JSON array line (an argument holding a newline stays one entry) and runs the real git; every `git` fake in these tests logs the same way, and the moving and occupying ones make their own extra git calls with the real git's absolute path, unlogged; the moving one also commits onto the stray named in the test just after the `for-each-ref --contains` call; the occupying one instead checks that stray out in a new worktree at that moment.
