# Stage bars

The bar a reviewer applies, by the work item's `stage:` (`pd-review-prompt` prints the matching section; shape.md StageBars).

## mvp

A blocker only when, left unfixed, an expectation in shape.md fails on the input it names, data is lost or exposed, or a security hole opens. Anything else is severity warning, category harden-later. Never relaxed: the security review for risk: security, blockers R0 and QB<n>, the token budget, validation at trust boundaries.

## production

Each checklist item applies as written.
